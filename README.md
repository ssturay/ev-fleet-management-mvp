
# EV Fleet Management MVP

## Purpose
Demonstration MVP for EV fleet tracking, charging, and operations.

## Live Demo Walkthrough (MVP)

This MVP demonstrates a web-based Electric Vehicle Fleet Management Platform
designed for the first EV deployment in Freetown, Sierra Leone.

### Demo Flow
1. Fleet registration and configuration
2. Real-time vehicle visibility on map
3. Battery monitoring and charging logic
4. Service-based vehicle allocation
5. Operational decision support

### Supported Service Models
- Ride-hailing (Call-a-Ride)
- Corporate Hire
- Airport & Seacoach Shuttle
- Daily Rentals
- Tourism Shuttles
- School Transport


## Run Instructions
Backend:
- cd backend
- npm install
- npx prisma migrate dev
- npm start

Frontend:
- cd frontend
- npm install
- npm run dev
